# LashJavaSwing
LashStudio - Sistema para Lash Design

Trabalho prático para gestão de atendimento e organização de um estúdio de extensão de cílios (Lash Design).

📌 Tema do Projeto

O projeto consiste em um sistema simples para ajudar a profissional de Lash Design a controlar seus agendamentos, cadastrar clientes com a ficha de anamnese, gerenciar os procedimentos oferecidos e acompanhar o estoque de insumos (como colas e cílios).

💾 Banco de Dados

Para o armazenamento das informações, utilizamos o banco de dados SQLite, por ser uma opção leve, simples de configurar e que não precisa de um servidor complexo rodando em segundo plano.
